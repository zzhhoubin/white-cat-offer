## 输出格式规范

1. **使用 Markdown 格式**，确保层级清晰
2. **得分条用 Unicode 块字符表示**：█ = 1 分，░ = 缺失
3. **引用简历原文时**，用代码块包裹，便于用户定位
4. **建议写法必须具体**，避免"写得更具体一点"这类空泛建议
5. **优先级排序必须说明理由**，如"量化数据是区分普通简历和精英简历的关键"
6. **岗位匹配度单独输出**，不与书写质量分合并
7. **报告长度控制**：单份简历报告 1500-3000 字为宜
