# 简历库 / 素材库 — 原型设计说明

> 版本：V0.1 · 导航「简历和素材库」拆为两个独立页面 · 交互原型见 `resume-materials-prototype.html`

---

## 1. 模块定位

| 页面 | 用户价值 |
|------|----------|
| 简历库 | 管理多份简历；设默认；供模拟面试 / 实时辅助选用 |
| 素材库 | 管理结构化素材（项目/经历/技能等）；供检索与题库生成 |

**与现状差异**：不再用同一页 `?tab=` 切换，下拉进入**不同路由页面**。

---

## 2. 信息架构与路由（建议）

```
导航 · 简历和素材库
├─ 简历库  → /resume          （原 /resume?tab=resume）
└─ 素材库  → /materials       （新页；原 /resume?tab=assets）
```

| 菜单项 | 路由 | 页面 |
|--------|------|------|
| 简历库 | `/resume` | 多简历列表 |
| 素材库 | `/materials` | 多素材列表 |

---

## 3. 屏 1 · 简历库

### 布局

```
顶栏
└─ 标题「简历库」 + [上传简历]
   └─ 列表（或空态）
        行：名称 · 格式/大小 · 上传时间 · 状态 · [设为默认][预览][删除]
        展开：解析摘要（素材条数等）
```

### 列表字段

| 字段 | 说明 |
|------|------|
| 名称 | 文件名 / 用户自定义显示名 |
| 格式 | PDF / Word / TXT |
| 状态 | 解析中 / 已解析 / 失败 |
| 默认 | 全局仅一份；面试配置默认选中 |
| 操作 | 设为默认、预览、删除 |

### 交互

- 上传：弹窗选文件 → 列表新增 → 模拟「解析中 → 已解析」
- 设为默认：互斥；删除默认份时自动把第一份设为默认（可再议）
- 行点击展开摘要；删除需确认

---

## 4. 屏 2 · 素材库

### 布局

```
顶栏
└─ 标题「素材库」 + [上传素材]
   └─ 类型筛选：全部 / 项目 / 经历 / 技能 / 其他
   └─ 列表（或空态）
        行：类型标签 · 标题 · 来源 · 更新时间 · [编辑][删除]
        展开：内容正文
```

### 列表字段

| 字段 | 说明 |
|------|------|
| 类型 | 项目 / 经历 / 技能 / 其他 |
| 标题 | 短标题 |
| 内容 | 摘要或全文 |
| 来源 | 简历解析 / 手动上传 |
| 操作 | 编辑、删除 |

### 交互

- 上传：类型 + 标题 + 内容 → 加入列表
- 筛选按类型
- 正式版可与「简历解析完成」自动写入联动（原型仅文案提示）

---

## 5. 空态

| 页 | 文案要点 |
|----|----------|
| 简历库 | 还没有简历 → 引导上传 |
| 素材库 | 还没有素材 → 引导上传或从简历解析 |

3. 拆分现有 `Resume.jsx` 为两页，或新建 `Materials.jsx`
