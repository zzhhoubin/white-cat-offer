# 资料库 · 经历总结（同页原型）

## 约束

- **不新增 Tab**
- **不弹新窗口 / 不抽屉**
- 文件与经历在同一页面

## 结构

```
我的资料库
├─ 上：文件区（现有网盘工具栏 + 列表）
│     工具栏右侧：「生成我的经历」
└─ 下：经历区（同页固定区块）
      空态 → 生成中 → 经历列表（页内手风琴展开详情）
```

## 经历档案字段（对齐参考 Skill）

1. 标题 / 组织 / 角色 / 时间  
2. 核心亮点  
3. 完整故事线（背景→问题→动作→结果）  
4. 项目详情描述  
5. 数据与落地成果  
6. 行业认知总结  
7. 个人经验沉淀  
8. 来源材料

## 可点击原型

打开：`prototypes/library-experiences-prototype.html`

1. 点「生成我的经历」→ 进度 → Mock 两段经历  
2. 点某条 → 页内展开完整档案  
3. 「重新生成」再走进度  

正式实现时：LLM 读资料库全文 → 聚类多段经历 → 后端持久化（供简历等模块调用）。
