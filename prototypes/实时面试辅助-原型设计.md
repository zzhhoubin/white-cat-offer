# 实时面试辅助 — 原型设计说明

> 版本：V0.1 · 对齐技术方案（系统音频旁听 + ASR + 流式提纲）· 交互原型见 `realtime-assist-prototype.html`

---

## 1. 模块定位

| 角色 | 职责 |
|------|------|
| 用户价值 | 真实线上面试中，自动识别面试官问题并给出可扫读的参考提纲 |
| 产品形态 | 旁听 + 单向建议（不替用户发言） |
| 与模拟面试 | 共用 ASR / 素材检索 / 提纲生成；编排独立 |

---

## 2. 页面结构

```
全站顶栏
└─ /interview/assist
   ├─ 左侧步骤条：配置 → 进行中 → 会话小结
   └─ 右侧主内容 + 进行中桌面浮窗
```

| 屏幕 | 核心内容 |
|------|---------|
| 配置 | 简历、JD、音频源、回答形态 → 开始监听 |
| 进行中 | 管线状态、当前问题、流式提纲、本场历史、可拖浮窗 |
| 会话小结 | 问题数、平均首包、问答回顾、加入题库 |

---

## 3. 屏幕说明

### 3.1 配置

- 音频源：**系统音频（推荐）** / 仅麦克风（降级）
- 回答形态：**提纲优先**（默认）/ 完整话术
- 须知：勿照念、需授权、`Ctrl+\` 隐身

### 3.2 进行中

**主区**
- 状态胶囊：监听中 / 识别中 / 生成中
- 管线：采集 → 识别 → 生成 → 就绪
- 当前问题卡（ASR）+ 参考回答区（流式）
- 本场已识别列表（可点回看）
- 操作：隐身浮窗 · 模拟下一题（原型）· 结束会话

**浮窗**
- 置顶半透明；标题栏可拖
- 展示当前问题 + 前几条要点
- 隐身 / 结束；热键 `Ctrl+\`

### 3.3 会话小结

- 识别问题数、平均首包（模拟）、音频源与形态
- 逐题回顾 +「加入题库」
- CTA：再开一场 · 去模拟面试

---

## 4. 交互规则

| 动作 | 行为 |
|------|------|
| 开始监听 | 模拟授权 → 进入进行中 → 自动演示首题 |
| 问题确认 | ASR partial → final → 触发流式提纲 |
| 模拟下一题 | 原型用假数据推进下一题 |
| 复制提纲 | 复制当前要点列表 |
| 展开完整话术 | 在提纲基础上展示口语化全文 |
| 隐身 | 浮窗透明不可点；再按热键恢复 |
| 结束 | 进入小结；可回填题库 |

---

## 5. 状态机（前端）

```
idle(配置) ──开始监听──► listening
listening ──VAD/ASR──► recognizing
recognizing ──问题确认──► generating
generating ──流式结束──► listening
任意进行中 ──结束──► summary
summary ──再开一场──► idle
```
