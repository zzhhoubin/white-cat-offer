# AI 实时辅助 v2 · 原型设计

> 可点击原型：`prototypes/realtime-assist-v2-prototype.html`  
> 目标：重构实时辅助的首页入口、配置弹窗、音视频配置与面试中布局。

---

## 1. 用户路径

```
首页（面试记录 / 空态欢迎）
  → 新建面试
  → 弹窗① 面试配置 → 下一步
  → 弹窗② 音视频配置 → 开始面试
  → 面试进行中
  → 结束 → 回首页并写入一条记录卡
```

---

## 2. 界面说明

### 2.1 首页

- 左上：`+ 新建面试`
- 无记录：居中文案  
  「欢迎使用面试助手，点击新建面试，即刻开始面试之旅，祝你好运连连」
- 有记录：中部卡片列表（职位类型 / 语言标签 / 时间 / 题数）

### 2.2 面试配置弹窗（屏幕居中）

| 字段 | 控件 |
|------|------|
| 面试简历 | 下拉 + 上传（占位） |
| 面试 JD | 多行文本 |
| 定制知识库 | 不使用 / 资料库 / 经历 |
| 职位类型 * | 下拉 |
| 编程语言 * | **下拉多选**（勾选列表，触发条展示已选标签） |
| 协议 | 勾选同意 |

校验通过后「下一步」。

### 2.3 音视频配置

- 麦克风：设备下拉 + 测试（电平条 Mock）
- 扬声器：设备下拉 + 测试（提示音 Mock）
- 「上一步」回配置；「开始面试」进入进行中页

### 2.4 面试进行中（全宽，参考附图）

- **无左右页边留白**，工作区贴边铺满  
- **竖向拖拽条**：调节左/右栏宽度  
- **横向拖拽条**：调节左侧「对话记录」与「识别问题」高度  

```
顶栏（全宽）：状态 · 职位/语言标签 · 模拟识别 · 结束
┌──────────────────┬─┬──────────────────┐
│ 左上 对话记录     │拖│ 右：AI 参考回答   │
│ （可滚动）        │拽│ （含仅供参考条）  │
├────────拖拽──────┤  │                  │
│ 左下 识别问题     │  │                  │
│ + 底部输入发送    │  │                  │
└──────────────────┴─┴──────────────────┘
```

---

## 3. 原型可点交互

1. 空首页 → 新建面试 → 填配置 → 下一步  
2. 测麦克风 / 扬声器 → 开始面试  
3. 「模拟识别下一题」或右下发送 → 更新问题与回答  
4. 结束 → 首页出现记录卡  

---

## 4. 与现网对照（后续实现参考）

| 现网 | v2 目标 |
|------|---------|
| `RealtimeAssist.jsx` 左步骤条 + setup/active/summary | 首页记录 + 双步弹窗 + 新进行中四区 |
| 配置页内嵌选简历/JD | 弹窗居中配置 |
| 进行中三栏（面试官/回答/列表） | 左对话+问题 / 右回答+输入 |

实现时可复用现有 WS、ASR、`answer` 生成；本原型不接后端。

---

## 5. 验收（原型）

- [ ] 首页左上有新建面试；空态文案正确  
- [ ] 配置弹窗居中，必填未完成无法下一步  
- [ ] 音视频可测后可开始面试  
- [ ] 进行中四区布局与滚动、手输发送可用  
- [ ] 结束后首页出现记录
