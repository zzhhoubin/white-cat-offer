# AI 模拟面试 — 原型设计说明

> 版本：V0.1 · 对齐 PRD 8.4 / 6.4 · 交互原型见 `mock-interview-prototype.html`

---

## 1. 模块定位

| 角色 | 职责 |
|------|------|
| 用户价值 | 预演真实三轮面试，暴露素材缺口与表达问题 |
| 产品验证 | 同步测试「问题识别 + 回答提纲」实时辅助能力 |
| 数据闭环 | 复盘结果反哺专属题库与个人素材库 |

**与实时辅助关系**：共用 ASR、素材检索、提纲生成；编排层独立（模拟 = 双向对话，实时 = 旁听 + 单向建议）。

## 2. 页面结构

```
全站顶栏
└─ /interview/mock
   ├─ 左侧步骤条（fixed，可视区垂直居中，无外框）
   │    ○ 配置 ──→ ○ 进行中 ──→ ○ 复盘报告
   └─ 右侧主内容
        ├─ 配置：3 步向导
        ├─ 进行中：单栏上下布局
        └─ 复盘报告
```

| 屏幕 | 路由 | 核心内容 |
|------|------|---------|
| 配置 | `/interview/mock` | 简历、JD、偏好 |
| 进行中 | 同上 phase=active | 问答 + 「给点参考」按需提纲 |
| 复盘报告 | 同上 phase=report | 总分、逐题反馈 |

## 3. 屏幕线框

### 3.1 配置向导

（同前：简历 → JD → 偏好）

- Step 3 说明：面试中点击「给点参考」按需获取提纲，不自动展示

### 3.2 面试进行中（单栏）

```
顶栏：轮次 · 题序 · 进度条 · [语音] [结束面试]
─────────────────────────────────
面试官卡片（问题 + 考察点）
回答区 + [跳过] [提交]
        [ 给点参考 ]     ← 点击后展开提纲
实时回答提纲（默认隐藏）
```

- **无**「本轮记录」侧栏
- 切题 / 提交后自动收起提纲

### 3.3 复盘报告

（总分 + 维度 + 逐题反馈 + CTA）

---

## 3.x 旧版双栏设计（已废弃）

<!-- 以下为 V0.1 初稿，已实现为单栏 + 按需提纲 -->

**交互规则**
- 提交后：面试官不出评价，直接下一题或追问
- 追问：题目标记「追问 · 第 N 层」，最多 3 层
- 轮次切换：展示过渡语 2s，顶栏轮次标签更新
- 语音：录音 → ASR → 填入输入框，用户可编辑后提交
- 辅助提纲：与当前问题同步生成，面试中只展示建议，不展示分数

**用户指令**
| 指令 | 行为 |
|------|------|
| 跳过 | 记录 skip，进入下一题 |
| 暂停 | 冻结计时，保留当前题 |
| 结束面试 | 基于已答内容生成报告 |

---

### 3.3 当场小结

- 总分 / 100 + 等级（A/B/C/D）
- 一句话总结 + 录用倾向说明（练习参考，非录取预测）
- 维度雷达或四宫格：表达、逻辑、经历贴合、风险应对
- CTA：查看完整报告 · 下载 HTML · 再来一次 · 加入题库

---

### 3.4 复盘报告（完整）

**区块顺序**
1. 头部：岗位、公司、日期、会话 ID
2. 总分 + 维度得分
3. 分轮次逐题卡片：
   - 原题 / 用户回答摘要 / 得分
   - 亮点 / 不足 / 改进建议
   - 参考提纲（基于用户素材，非万能模板）
4. 素材缺口清单 → 「补充素材」「加入题库」
5. 下一步练习建议

## 4. 会话状态机

```
                    ┌──────────┐
                    │  created │
                    └────┬─────┘
                         │ prepare()
                         ▼
                    ┌──────────┐
         ┌─────────│ preparing│─────────┐
         │         └────┬─────┘         │ fail
         │              │ ready         ▼
         │              ▼          ┌────────┐
         │         ┌──────────┐    │ failed │
         │         │  active  │    └────────┘
         │         └────┬─────┘
         │    answer / skip / followup
         │              │
         │    round_transition (hr→business→final)
         │              │
         │         all_questions_done OR user_finish
         │              ▼
         │         ┌──────────┐
         └────────►│ scoring  │
                   └────┬─────┘
                        ▼
                   ┌──────────┐
                   │ finished │
                   └──────────┘
```

**状态字段**

| 字段 | 类型 | 说明 |
|------|------|------|
| session_id | string | 会话 ID |
| session_type | enum | `mock` |
| status | enum | created / preparing / active / scoring / finished / failed |
| config | object | resume_id, jd_text, role, company, scope, language |
| engine_state | object | round_index, question_index, followup_depth |
| assist_enabled | bool | 是否展示提纲面板，MVP 默认 true |
| transcript_log | array | [{role, text, ts}] |
| question_log | array | 见下表 |
| report_id | string | 关联报告 |

**question_log 单条**

| 字段 | 说明 |
|------|------|
| index | 全局题序 |
| round | hr / business / final |
| question | 题目文本 |
| intent | 考察点 |
| is_followup | 是否追问 |
| followup_depth | 0–3 |
| answer_text | 用户回答 |
| skipped | 是否跳过 |
| outline | 系统生成的提纲快照 |
| score | 面试结束后填充 |
| feedback | 亮点/不足/建议 |

## 5. API 草案（REST）

| 方法 | 路径 | 说明 |
|------|------|------|
| POST | `/api/mock-interviews` | 创建会话 + prepare |
| GET | `/api/mock-interviews/{sid}` | 获取会话状态 |
| POST | `/api/mock-interviews/{sid}/next` | 获取下一题 |
| POST | `/api/mock-interviews/{sid}/answers` | 提交回答 |
| POST | `/api/mock-interviews/{sid}/outline` | 按需生成当前题提纲 |
| POST | `/api/mock-interviews/{sid}/skip` | 跳过当前题 |
| POST | `/api/mock-interviews/{sid}/finish` | 提前结束并评分 |
| GET | `/api/mock-interviews/{sid}/report` | 报告 JSON |
| GET | `/api/mock-interviews/{sid}/report.html` | HTML 报告 |

**WebSocket**（语音）
- 路径：`/ws/session?mode=mock&token=...`
- 上行：PCM 音频帧
- 下行：`transcript` / `info` / `ready`

## 6. AI 编排（Skill 分层）

```
mock-interview/
├── SKILL.md                 # 编排入口
├── roles/hr.md              # HR 面：动机、稳定性、反问
├── roles/business.md        # 业务面：项目深挖、情景题
├── roles/final.md           # 终面：思维、行业、成长
├── follow-up-rules.md       # 追问触发（笼统/漏洞/值得展开）
├── scoring-rubric.md        # 评分区分度（好 9-10，差 3-4）
└── report-spec.md           # 报告模板
```

**Orchestrator 逻辑**
1. 按 `round` 加载 role prompt
2. 从专属题库检索 + LLM 动态补题
3. 用户回答后：`follow-up-rules` 判断是否追问
4. 并行调用「提纲生成」（与实时辅助同一 pipeline）
5. 全部结束后：`Evaluator` 读取 `scoring-rubric` + `report-spec` 出报告

## 7. MVP 边界

**必做**
- 完整三轮（HR 5 + 业务 7 + 终面 4 题上限）
- 每轮至少 1 次追问
- 语音 + 文字双模式作答
- 默认开启回答提纲侧栏
- 结束后逐题评分报告
- 报告题目可加入专属题库

**不做**
- 面经搜索 / 公司定制题
- 面试中实时打断纠正
- 视频 / 表情分析
- 英文面试（配置项保留，MVP 不开放）

**免费额度建议**：1 次完整三轮 / 周

## 9. 验收清单

- [ ] 用户能在 3 步内完成配置并开始面试
- [ ] 一题一题提问，过程中无评分泄露
- [ ] 至少一轮追问，追问标记清晰
- [ ] 侧栏同步展示当前题提纲
- [ ] 语音回答可转写、可编辑、可提交
- [ ] 提前结束仍能生成部分报告
- [ ] 完整报告含逐题反馈与参考提纲
- [ ] 报告题目可一键加入专属题库
