# AI 实时辅助 · 进行中 — 三栏原型说明

> 版本：V0.1 · 参考 OfferGoose 进行中布局 · 交互原型见 `realtime-assist-active-prototype.html`

---

## 1. 页面定位

仅覆盖 **实时辅助 · 进行中**。配置页 / 会话小结不在本原型范围。

目标：听清当前问题、扫读参考回答、必要时手输问题、回看本场问题列表。

---

## 2. 整体布局

```
┌─────────────────────────────────────────────────────────────┐
│ 顶栏：品牌 · 监听状态 · 时长 · [模拟识别] [结束]               │
├──────────────┬──────────────────────────┬───────────────────┤
│ 左上          │ 中上                      │ 右                 │
│ 面试官标识    │ 参考回答（重点高亮）       │ 问题列表           │
│ + 当前问题    │ + 回答结构                │                   │
│              │                          │                   │
│ 左下          │ 中下                      │                   │
│ 当前 JD       │ 手动输入问题 + 发送       │                   │
└──────────────┴──────────────────────────┴───────────────────┘
```

栅格建议：`280px | 1fr | 260px`；窄屏改为单列堆叠。

---

## 3. 分区说明

### 3.1 顶栏

| 元素 | 说明 |
|------|------|
| 状态胶囊 | 监听中 / 识别中 / 生成中 |
| 时长 | 本场计时 |
| 结束 | 进入小结（正式版） |

### 3.2 左栏

**上：面试官 + 当前问题**
- 圆形头像/图标 +「面试官」
- 当前问题大字展示（ASR 或手动）
- 来源提示：语音识别 / 手动输入

**下：当前 JD**
- 岗位名、JD 摘要、关键词 chips
- 数据来自配置页

### 3.3 中栏

**上：参考回答**
- AI 口语化完整答案；重点词高亮（如团队名、指标）
- 下方附「回答结构」列表（与现网双栏能力对齐，收进同一主卡片）

**下：手动输入**
- 音频不可用或未识别时，输入面试官问题
- 发送 → 调 LLM（原型用假数据）
- Enter 发送，Shift+Enter 换行

### 3.4 右栏

- 本场问题列表（题序 + 摘要）
- 点击切换当前问题与对应参考回答
- 空态：「本场暂无问题」

---

## 4. 交互流（原型）

1. 进入页 → 自动「模拟识别」首题 → 生成参考回答 → 右侧入列  
2. 「模拟识别下一题」→ 再走一轮  
3. 中下手动输入 → 发送 → 同样生成并入列  
4. 右侧点击 → 左/中同步切换
