# AI 模拟面试 v2 · 原型设计

> 可点击原型：`prototypes/mock-interview-v2-prototype.html`  
> 需求来源：`产品需求文档.md` 模拟面试章节  
> 风格对齐：AI 实时辅助 v2（绿主题、居中弹窗、全宽面试页、可拖拽分隔）

---

## 1. 用户路径

```
首页（模拟记录 / 空态欢迎）
  → 新建模拟面试
  → 弹窗① 面试配置 → 下一步
  → 弹窗② 音视频配置 → 开始面试
  → 模拟面试进行中（按题作答）
  → 结束 → 回首页并写入记录卡
```

---

## 2. 界面说明

### 2.1 首页

- 左上：`+ 新建模拟面试`
- 无记录：居中文案  
  「欢迎使用模拟面试助手，通过多练习多总结，一定能拿到心仪offer，祝你好运连连」
- 有记录：卡片（职位类型 / 语言 / 时间 / 已答题数）

### 2.2 面试配置弹窗

| 字段 | 控件 |
|------|------|
| 面试简历 | 下拉 + 上传（占位） |
| 面试 JD | 多行文本 |
| 定制知识库 | 不使用 / 资料库 / 经历 |
| 职位类型 * | 二级联动（左一级 / 右二级） |
| 编程语言 * | 多选，首位「无」，与其它语言互斥 |
| 协议 | 勾选同意 |

### 2.3 音视频配置

- 麦克风：设备 + 测试（电平 Mock）
- 扬声器：设备 + 测试（提示音 Mock）
- 「开始面试」进入进行中页

### 2.4 模拟面试页（全宽）

```
顶栏：状态 · 计时 · 职位/语言 · 进度 · 结束
┌──────────────┬─┬─────────────────────┐
│ 左：已出现题目│拖│ 右上：作答展示       │
│ · 仅顺序追加  │拽│ · 用户回答内容       │
│ · 当前问题标签│  │ · 最下方参考回答     │
│ · 已答可回看  │  ├────────拖拽─────────┤
│              │  │ 右下：控制区         │
│              │  │ 上一题/下一题/参考   │
│              │  │ 文本框 + 语音 + 提交 │
└──────────────┴─┴─────────────────────┘
```

**出题逻辑（原型）**

1. 初始左侧仅展示第 1 题；新题倒序置顶，「当前问题」在最上方  
2. 「下一题」随时可点（不强制先提交），流式追加无上限  
3. 「结束面试」停止出题；首页记录卡「复盘」生成分析报告  
4. 已出现题目可回看；「查看参考」在右上区最下方

---

## 3. 原型可点交互

1. 空首页 → 新建 → 填配置（职位二级 + 语言）→ 下一步  
2. 测麦/扬声器 → 开始面试  
3. 文本作答 / 语音 Mock 转写 → 提交 → 下一题  
4. 回看已答题、查看参考、拖拽分隔条  
5. 结束确认 → 首页出现记录  

---

## 4. 与现网对照（后续实现）

| 现网 `Interview.jsx` Mock | v2 目标 |
|---------------------------|---------|
| 左步骤条 + 三步配置页 | 首页记录 + 双步弹窗 |
| 单栏问答栈 | 左题列表 / 右展示+作答 |
| 无分隔条 | 竖/横拖拽分隔 |
| 结束进报告页 | 先回首页写记录（报告可二期） |

复用现有 Mock API / 出题 / 评分链路；本原型不接后端。

---

## 5. 验收（原型）

- [ ] 首页左上有新建；空态文案正确  
- [ ] 配置弹窗居中，必填未完成无法下一步  
- [ ] 职位二级、语言含「无」可用  
- [ ] 音视频可测后可开始  
- [ ] 题列表倒序，当前题置顶；下一题无需先提交  
- [ ] 首页复盘按钮可生成分析报告 
- [ ] 右上展示作答，参考回答在右上区最下方 
- [ ] 右上展示 / 右下输入+语音+控制区可用  
- [ ] 面板可拖拽；结束后首页有记录
